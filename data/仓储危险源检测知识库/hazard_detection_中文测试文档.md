# 仓储场景危险源检测：概念、案例与检索问答

文档编号：HD-DEMO-2026-001  
语言：简体中文  
用途：向量库入库、文本切分、语义检索与检索增强生成（RAG）测试  
说明：本文中的企业、人员、事件、数值和规则均为虚构测试数据，不作为实际安全作业规范。

## 1. 项目背景

青禾物流测试中心计划建立一套危险源检测系统（Hazard Detection System），用于识别仓库照片中的潜在安全问题。系统接收现场图像，生成候选危险源、可见证据、位置描述和复核建议，再由人工判断是否需要处理。

该测试中心包含东区装卸口、南区货架区、西区充电区和北区人行通道。项目代号为“青禾哨兵”，测试负责人为林知远。第一轮虚构评估使用了240张图像，其中包含正常场景、明显异常场景和证据不足的场景。

系统的目标是帮助复核人员找到值得关注的位置。仅凭一张图片，系统通常无法确认设备内部状态、物品重量、地面摩擦系数或现场作业是否经过授权。

## 2. 核心概念

危险源是可能造成伤害或损失的对象、状态或行为。例如，横跨步行路线的电缆可以成为绊倒危险源。风险则描述某个危险源导致不良后果的可能性及其后果严重程度。危险源识别与风险评估相关，但不是同一个任务。

可见证据是图像中能够直接观察到的信息，例如“黄色延长线从左侧设备延伸到右侧货架，并横跨地面标记的人行路线”。“工作人员一定会被绊倒”不是可见证据，而是对未来结果的推测。

检测置信度表示模型对检测判断的确信程度，不等于事故发生概率。一个高置信度的障碍物检测结果，仍然可能对应较低的实际风险；一个低置信度结果，也可能涉及需要优先核实的严重问题。

## 3. 测试用危险源分类

### 3.1 通道占用与出口遮挡

当纸箱、托盘或运输设备占据通行区域时，系统记录“通道占用”候选项。如果图像显示物品位于出口门前，并妨碍通行，则可以记录“出口遮挡”候选项。出口标识可见，并不代表出口附近一定畅通。

检索同义表达包括：通道堵塞、过道被占、出口被挡住、通行受阻、逃生路线障碍物。

### 3.2 地面液体与滑倒隐患

地面出现疑似液体、反光斑块或滴落痕迹时，系统可以提出“疑似湿滑地面”。但光滑地砖的反射、阴影和透明塑料膜也可能产生相似视觉特征。无法确认时，应保存不确定性，而不是直接判断为漏水或漏油。

检索同义表达包括：地面积水、液体泄漏、地上有水、滑倒风险、湿滑区域。

### 3.3 电缆与绊倒隐患

跨越步行路线的松散电缆、翘起的地垫和低矮杂物，都可能被归入绊倒隐患。检测描述应包含物体所在位置及其与通行路线的关系。仅发现电缆存在，不能自动认定它构成通行障碍。

检索同义表达包括：线缆横穿过道、脚下障碍物、容易绊脚、地垫卷边。

### 3.4 货物堆放异常

测试系统关注货物明显倾斜、包装悬出支撑面、箱体严重变形等可见状态。照片可以显示堆放外观，却不能可靠给出货架承载能力或货物实际重量。因此，“货架超载”需要额外资料支持。

检索同义表达包括：箱子堆歪、货物突出、堆垛不稳、物品可能掉落。

### 3.5 人车空间冲突

当叉车与行人同时出现在相邻区域时，系统记录双方位置、路线标记和可见隔离设施。单张静态图像无法可靠判断车辆速度，也不能仅凭人员面朝方向确认其正在行走。

检索同义表达包括：人车混行、叉车靠近行人、行人与车辆交叉、行车通道有人。

## 4. 检测与复核流程

第一步是检查输入质量。画面过暗、模糊或被大面积遮挡时，系统标记“图像质量不足”，必要时请求补充图像。

第二步是提取候选危险源。模型给出类别、位置和证据描述。例如：“画面右下方有两个纸箱，部分覆盖蓝色人行通道标线。”

第三步是验证证据。复核环节检查描述是否对应图像内容，以及模型是否将推测误写成事实。对于看不清的标识、被遮挡的出口或无法辨认的液体，输出“待确认”。

第四步是去重。同一组纸箱可能同时触发“杂物堆放”和“通道占用”。如果两个结果描述同一对象、同一位置和同一问题，系统合并为一条记录，并保留原始检测来源。

第五步是人工处置和复查。人工确认结果可以是“确认存在”“误报”或“证据不足”。问题处理后，需要新的检查记录才能标记为“已关闭”，不能因为旧照片中不再显示该区域就自动关闭。

## 5. 虚构案例记录

### 案例 HD-101：东区装卸口纸箱占道

2026年9月12日09:20，测试图片显示东区装卸口有三个纸箱，其中两个进入蓝色人行通道标记范围。模型将其分类为“通道占用”，检测置信度为0.92。复核人员陈雨确认该区域属于步行路线，记录状态为“确认存在”。

09:45，纸箱转移至指定暂存区。09:52，陈雨通过补拍图片确认通道恢复畅通，将记录改为“已关闭”。本案例涉及三个纸箱，处置地点为东区装卸口，不涉及西区充电区。

### 案例 HD-102：南区货架旁疑似积水

2026年9月13日14:10，图片显示南区货架区地面有一块明亮反光区域。模型提出“疑似湿滑地面”，检测置信度为0.61。由于图像缺少清晰边缘和液体痕迹，人工初审结果为“证据不足”。

14:35，现场补充记录说明该反光来自铺在地面的透明包装膜，并非积水。因此，原有“疑似积水”候选项被标记为误报。包装膜是否造成其他通行问题，需要作为独立问题检查，不能沿用积水结论。

### 案例 HD-103：西区充电区电缆横穿步道

2026年9月14日11:05，西区充电区的一条黑色电缆横跨人行路线。模型输出“绊倒隐患”，检测置信度为0.88。人工确认电缆与步行区域存在交叉，但图片不足以判断电缆绝缘层是否损坏。

该记录的确认问题是“电缆影响通行”，不是“电缆漏电”。测试记录中，现场人员随后调整了线缆布置；由于尚未上传复查照片，该记录保持“待复查”状态。

### 案例 HD-104：北区通道中的叉车与行人

2026年9月15日16:40，北区人行通道附近出现一辆叉车和一名工作人员。模型提出“人车空间冲突”候选项。照片中可以看到部分隔离栏，但隔离栏是否连续、叉车是否移动均无法确认。

人工将该记录标为“证据不足”，要求补充更宽视角的图像或连续视频。本案例没有记录碰撞，也没有任何车辆超速的确认结论。

## 6. 记录字段建议

每条检测记录可以包含以下字段：

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| record_id | 唯一记录编号 | HD-103 |
| location | 场景位置 | 西区充电区 |
| hazard_category | 候选危险源类别 | 绊倒隐患 |
| visible_evidence | 可见证据 | 黑色电缆横跨人行路线 |
| confidence | 模型检测置信度 | 0.88 |
| review_result | 人工判断 | 确认存在 |
| workflow_status | 处理进度 | 待复查 |
| uncertainty | 尚未确认的信息 | 无法判断绝缘层是否损坏 |
